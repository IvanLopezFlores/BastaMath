# BastaMath

**BastaMath** es una adaptación matemática del juego tradicional *Basta*, desarrollada como una aplicación web sencilla con fines educativos.

El programa genera consignas matemáticas y propone al jugador responder antes de que termine el tiempo disponible.

## Objetivo

El proyecto busca mostrar cómo una mecánica de juego conocida puede transformarse mediante programación en una actividad para la enseñanza y el aprendizaje de las matemáticas.

Además, sirve como ejemplo de desarrollo de tecnología educativa con herramientas web básicas.

## Características

- Generación aleatoria de consignas matemáticas.
- Temporizador para responder.
- Síntesis de voz mediante el navegador.
- Controles para iniciar, pausar y reanudar el juego.
- Funcionamiento directamente desde un navegador web.
- No requiere instalación.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Web Speech API (`speechSynthesis`)

## Ejecutar el proyecto

Puede ejecutarse localmente abriendo el archivo:

`index.html`

en un navegador web.

También está disponible en línea mediante GitHub Pages:

https://ivanlopezflores.github.io/BastaMath/

## Uso educativo

BastaMath fue desarrollado como una exploración de las posibilidades de la programación para crear recursos interactivos destinados a la enseñanza de las matemáticas.

El proyecto permite discutir aspectos como:

- diseño de actividades matemáticas;
- generación automática de preguntas;
- interacción usuario-computadora;
- accesibilidad;
- reutilización y adaptación de software educativo.
